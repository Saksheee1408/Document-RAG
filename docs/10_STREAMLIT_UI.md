# Milestone 10 — Streamlit UI

## Goal

Give the reviewer a simple interface to ask questions and inspect answers.

## Required UI

Include:

1. Application title.
2. Question input.
3. Ask button.
4. Answer area.
5. Sources area.
6. Loading/progress state.
7. Friendly error messages.

## Suggested layout

RAG Document Q&A

Question:
[........................................]

[Ask]

Answer:
..........................................

Sources:
Document | Page | Chunk

## Optional features

Only after the core pipeline works:

- expandable source previews
- similarity score
- sample questions
- clear/reset
- index status
- conversation history

Do not spend excessive time on visual styling.

## Acceptance criteria

A reviewer can launch the application and ask questions without touching internal code.

The UI shows both answer and sources.
