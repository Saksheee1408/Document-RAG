# Milestone 11 — Sample Q&A Evaluation

## Goal

Demonstrate that the system works across different question types.

## Required deliverable

Create a `sample_qa.md` or equivalent file containing at least 10 questions.

At least 2 must be unanswerable.

## Recommended distribution

- 3 straightforward factual questions
- 2 paraphrased questions
- 2 table/specification questions
- 1 source-attribution-focused question
- 2 unanswerable questions

## Record for each question

- question
- expected behavior
- actual answer
- source document
- page
- retrieved chunk(s)
- correctness assessment

## Acceptance criteria

The examples demonstrate more than a single happy-path query.

The two or more unanswerable examples clearly demonstrate safe refusal rather than hallucination.
